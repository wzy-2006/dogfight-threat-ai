# 美术规范

> 本文是整个项目美术资源的**唯一约定**。新增素材前先读这里，改约定要全员同步。
> 关联：[素材台账](素材台账.md) · [第三方声明](../../THIRD-PARTY-NOTICES.md)

---

## 1. 全局 Pixels Per Unit（PPU）= **32**

这是最重要的一条，所有素材导入设置都以它为准。

| 素材 | 像素尺寸 | 世界单位 | 说明 |
|---|---|---|---|
| 飞机精灵 | 32 × 32 | **1.0 × 1.0** | Kenney Ships |
| 地形块 | 16 × 16 | **0.5 × 0.5** | Kenney Tiles |

代码里的常量在 [`DogfightConst.PixelsPerUnit`](../../src/client/DogfightThreatAI/Assets/Scripts/View/DogfightConst.cs)。

> 约定：**仿真内部一律用像素做单位**（速度 520 px/s、战场 3600×2600 px），
> 只在视图层除以 PPU 换算成世界单位。这样 config 里的数值读起来才直观，
> 也方便和策划案、算法论文里的数字对齐。

## 2. 导入设置（由 `PixelArtPostprocessor` 自动套用）

`Assets/Scripts/Editor/PixelArtPostprocessor.cs` 会对
`Assets/ThirdParty/kenney-pixel-shmup/` 下的所有贴图自动套用以下设置，
**不需要手工改 Inspector**：

| 设置项 | 值 | 原因 |
|---|---|---|
| Texture Type | Sprite (2D and UI) | 2D 工程 |
| Sprite Mode | Single | 用的是单图，不是图集 |
| Pixels Per Unit | **32** | 见第 1 节 |
| Filter Mode | **Point (no filter)** | 像素画必须关插值，否则会糊 |
| Mip Maps | 关闭 | 正交相机 + 固定缩放，不需要 |
| Compression | Uncompressed | 16×16 的图压缩反而更糟 |
| Alpha Is Transparency | 开启 | 去黑边 |
| **Read/Write Enabled** | **开启** | 程序化地表需要 `GetPixels32()` 读单块像素 |
| Wrap Mode | 地形块 = **Repeat**；飞机 = Clamp | 地形块用于 Tiled 绘制模式的视差背景 |

> ⚠️ 如果地形背景退化成纯色海面，八成是 **Read/Write 没开**。
> 执行菜单「空战 / ① 生成精灵台账」前先 `Reimport` 一次素材目录。

## 3. 目录与命名

```
art-source/                                   ← 原始归档，不进 Unity
├── original/{sprites,tiles,ui,vfx,audio,fonts,animations}/
└── third-party/kenney-pixel-shmup/
    ├── NOTES.md
    └── source/                               ← 上游原样保留，不要改

src/client/DogfightThreatAI/Assets/ThirdParty/kenney-pixel-shmup/   ← Unity 实际导入位置
├── Ships/     ship_0000.png … ship_0023.png
├── Tiles/     tile_0000.png … tile_0119.png
├── Tilemap/   （图集，暂未使用）
└── LICENSE-Kenney-PixelShmup.txt
```

| 规则 | 说明 |
|---|---|
| 第三方素材**一律**放 `Assets/ThirdParty/<素材包名>/` | **不要**放 `Assets/Plugins/`——那是 Unity 特殊目录，只放原生插件 `.dll/.so/.aar` |
| 不要改上游文件名 | 重命名会让素材台账与代码里的索引对不上 |
| `Preview.png` / `Sample.png` / `*.url` / `Tilesheet *.txt` 不导入 | 见 [NOTES.md](../../art-source/third-party/kenney-pixel-shmup/NOTES.md) |
| 自己产出的素材放 `art-source/original/` | 按类型分目录，同时导出 `.png` 与源文件（`.aseprite` / `.psd`） |
| 保留 `License.txt` | 随包保留，不要删 |

## 4. 精灵朝向约定

Kenney 的飞机精灵**机头朝上（+Y）**。而 Unity 里 `rotation.z = 0` 表示朝向 **+X**。

所以视图层的换算固定为：

```csharp
float deg = angle * Mathf.Rad2Deg - 90f;
transform.rotation = Quaternion.Euler(0f, 0f, deg);
```

仿真内部的角度统一为：**0 弧度 = +X 方向，逆时针为正**（与 Unity 2D 一致）。
新增朝向性素材（导弹、拖尾）时沿用同一条换算。

## 5. 排序层级

整个游戏**只用 Default 层**，靠 `sortingOrder` 控制前后关系——
这样不需要改 `ProjectSettings/TagManager.asset`（改 ProjectSettings 需要全员同步，成本高）。

| 层级 | sortingOrder | 内容 |
|---|---|---|
| 地表 | −200 | 海面 / 岛屿（多层视差最远层） |
| 海涌 | −199 | 第二层视差 |
| 云层 | −100 | 第三层视差 |
| 弹丸 | 0 | 机炮 / 导弹 |
| 飞机 | 10 | 玩家与敌机 |
| 特效 | 20 | 爆炸、命中火花 |

常量定义在 `DogfightConst.Order`。

## 6. 视差图层规范

| 图层 | parallax | 说明 |
|---|---|---|
| 海面/地表 | 0.30 | 最远，移动最慢 |
| 海涌 | 0.42 | 叠加层，软光混合 |
| 云层 | 0.62 | 带自身漂移 |
| （预留）前景 | 0.85+ | 尚未使用 |

`parallax` 的含义：相机移动 1 个单位，该图层移动 `parallax` 个单位。

## 7. 色彩

| 用途 | 色值 | 来源 |
|---|---|---|
| 玩家机 | 原色（不染色） | `ship_0000` 自带蓝色 |
| 敌机 | 统一染 `(1.0, 0.62, 0.62)` | `SpriteBank.EnemyTint`，让同款机型区分敌我 |
| 海面 | `#DFF6F5` | 图块 `42`，实测 100% 单色 |
| 草地 | `#B6D53C` | 图块 `50` |
| 沙地 | `#CB815E` | 图块 `56` |
| 相机背景 | `(0.02, 0.05, 0.09)` | 深空色 |

## 8. 新增素材的检查清单

- [ ] 尺寸符合 PPU=32 的整数倍（1 格 = 32×32，半格 = 16×16）
- [ ] 放进 `Assets/ThirdParty/`（第三方）或 `art-source/original/`（自制）
- [ ] 在 [素材台账](素材台账.md) 登记来源与授权
- [ ] 若是第三方，更新 [THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md)
- [ ] 朝向符合第 4 节约定
- [ ] `.meta` 文件**与素材在同一次提交里**
- [ ] 单文件 < 50 MB
