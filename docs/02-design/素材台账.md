## 三、待补清单（Kenney 包**没有**的东西）

Pixel Shmup 只有飞机与地形，以下全部缺，需要另外补：

| 缺口 | 当前替代方案 | 优先级 |
|---|---|---|
| 子弹 / 弹幕贴图 | 复用图块 `0`（黄色弹丸） | 低——够用 |
| 爆炸 / 尾焰序列帧 | 复用图块 `4`~`9` | 低——够用 |
| 导弹尾迹 | 复用图块 `8` `9` + 代码拖尾 | 中 |
| HUD / 血条 / 雷达 UI | IMGUI 程序化绘制 | 中——第二阶段换 uGUI |
| 字体 | IMGUI 内置字体（可能缺中文字形） | **中高**——建议尽快换成带中文字形的 TMP 字体 |
| 音效与音乐 | **Unity 版尚未实现** | 中 |
| 战机动画（翻滚 / 受损） | 无，只做整体旋转 | 低 |

## 四、登记流程

1. 把素材放进 `art-source/`（自制 → `original/`，第三方 → `third-party/`）
2. 在本文件新增一行，填齐：名称 / 作者 / 来源 / 授权 / 归档位置 / 状态
3. 若是第三方，同步更新 [`THIRD-PARTY-NOTICES.md`](../../THIRD-PARTY-NOTICES.md)
4. 导入到 `Assets/ThirdParty/<包名>/`（或自制放 `Assets/Art/`）
5. 确认 `.meta` 与素材在**同一次提交**
6. 自检：贴图 Read/Write 是否打开、Filter 是否 Point、PPU 是否 32
