## 二、第一次运行

### 1. 打开工程

用 Unity Hub「Add project from disk」选择：

```
src/client/DogfightThreatAI/
```

首次打开会导入 148 个素材并编译脚本，通常需要 1~3 分钟。

### 2. 一键搭建

菜单 **空战 → ③ 一键搭建（资源 + 场景）**

完成后会自动打开 `Assets/Scenes/Dogfight.unity`。按 **Play**。

> 如果不想用一键搭建：打开任意场景直接按 Play 也能跑。
> `GameBootstrap` 会自动创建相机、背景与战斗机。

### 3. 如果画面不对

| 现象 | 原因 | 处理 |
|---|---|---|
| 背景是纯深色，没有海面和岛屿 | 贴图没有勾 **Read/Write Enabled**，程序化地表读不到像素 | 选中 `Assets/ThirdParty/kenney-pixel-shmup/Tiles` → 右键 **Reimport**；或执行菜单「空战 → ① 生成精灵台账」 |
| 飞机是一个纯色三角形 | 没找到精灵台账 | 执行菜单「空战 → ① 生成精灵台账」 |
| 中文显示成方块 | IMGUI 内置字体缺中文字形 | 选中 HUD 对象，取消勾选 `Use Chinese Labels`（切成英文标签） |
| 完全没有画面 / 一直黑屏 | 场景里没有相机 | 执行「空战 → ③ 一键搭建」，或手工建一个正交相机 |
| 编译报错 | 见 [README 第二节](../../README.md) | 先跑 `tools\unity-verify\验证.bat` 定位 |

## 三、操作说明

### 飞行

游戏有两种操控方案，按 **V** 随时切换。

#### 方案 A：物理飞行（默认）

| 按键 | 作用 |
|---|---|
| `W` / `↑` | 加大油门 |
| `S` / `↓` | 收油门 |
| `A` `D` / `←` `→` | 左右压杆转向 |
| `Ctrl` | 减速板（额外阻力，快速掉速） |

这架飞机**有惯性**：收油门不会立刻停下，而是滑行减速。

**速度决定舵效**：达到 150 px/s 以上才有满舵效，低于最小速度会失速（舵效掉到三成）。
所以**保持空速**才转得动；低速时硬拉杆是转不过来的。

被咬尾时，`Ctrl` 减速板配合压杆比单纯硬拉更有效——对手会冲到前面去。

#### 方案 B：街机

`W` `A` `S` `D` 直接给航向，飞机自动转向并推满油门。适合不熟悉飞行手感的玩家。

### 武器

| 武器 | 操作 | 特点 |
|---|---|---|
| 机炮 | `空格` / 鼠标左键 | 弹速快（1020 px/s）、伤害低（7）、**会过热**。持续扣扳机约 4.9 秒触发过热，散热约 2.2 秒。做成点射更划算 |
| 导弹 | `Shift` / 鼠标右键 | 伤害 38、有导引头与近炸引信。**按住**开始锁定（锥角 ±35°、射程 1250 px），锁定进度满 1 秒后自动发射；未锁定就松手则是无制导发射 |

机炮弹丸会**继承载机速度**——高速迎头射击时弹速更猛。

### 系统

| 按键 | 作用 |
|---|---|
| `P` / `Esc` | 暂停 / 继续 |
| `R` | 重开一局（随机新种子） |
| `F1` | 无敌模式（调试用） |
| `F2` | 显示**威胁网格** |
| `F3` | 云层开关（觉得背景有雾感就按它） |
| `V` | 切换操控方案 |

### 背景 / 画面

| 想要的效果 | 怎么做 |
|---|---|
| 关掉云层（背景更干净） | 按 `F3` |
| 彻底关掉所有视差背景 | 选中 `Dogfight` 对象，取消勾选 `Enable Parallax` |
| 只关地表、保留海面纯色 | 取消勾选 `Enable Generated Terrain` |
| 调云层浓淡 | 改 `Cloud Opacity`（默认 0.42）；`0` 等于关掉 |
| 云更少 / 更小 | 调小 `Cloud Count`（默认 9）与 `Cloud Max Alpha`（默认 0.35） |
| 换个地形种子 | 改 `Terrain` 下的 `Seed` |

## 四、玩法

### 目标

从标题界面开始，逐波击落敌机，共 **20 波**。你有 **3 条命**，被击落后 0.6 秒在战场中心复活。
三条命耗尽即结束。

### 计分

| 来源 | 分数 |
|---|---|
| 击落侦察机 / 战斗机 / 导弹机 / 重型截击机 | 100 / 180 / 240 / 420 |
| 连杀加成 | 每多一连杀 +15%，连杀窗口 2.5 秒 |
| 清空一波 | 250 + 波次 × 50 |
| 撞机击落 | 按 60% 计 |

### 三档 AI

开局前在菜单里选，或在 `GameConfig` 里改 `DefaultAiProfile`：

| 档位 | 特点 | 反应时间 | 瞄准误差 | 规避阈值 | 规避规划 |
|---|---|---|---|---|---|
| **新兵** | 反应迟缓、直线追击、很少规避 | 0.50 s | 0.20 rad | 0.68 | 直接转向 |
| **老兵** | 会算提前量、会脱离 | 0.24 s | 0.09 rad | 0.60 | **A\*** |
| **王牌** | 预判走位、用威胁场规划规避、导弹压制 | 0.11 s | 0.032 rad | 0.52 | **A\*** |

难度差异来自**算法质量**，不是靠加血加伤害：

- 反应时间决定决策刷新频率；
- 瞄准误差决定打得多准；
- 提前量准确度决定追不追得上；
- 规避阈值决定多早开始躲；
- 规划器决定规避是「埋头直飞」还是「沿威胁梯度用 A\* 绕出去」。

### 敌机行为

敌机会实时评估战场威胁，在五种行为之间动态切换：

| 行为 | 触发条件 | 表现 |
|---|---|---|
| 巡逻 | 无目标、无已知位置 | 沿低威胁航路点巡航 |
| 搜索 | 有目标但丢失视野 | BFS 找最近的未侦察空域 |
| 追击 | 目标距离 > 射程 × 1.4 | 按提前量追击，接近时收油门 |
| 攻击 | 目标进入射程与包线 | 瞄准开火，条件满足时放导弹 |
| 规避 | 威胁超过阈值 | 用 A\* 沿威胁梯度飞出低风险航线 |

**按 `F2` 可以直接看到 AI 眼里的威胁网格**——红色越深代表 AI 觉得那里越危险。
这是理解本项目核心机制最直观的方式，答辩演示时非常好用。

### 战场边界

战场是 3600 × 2600 的矩形。飞出边界不会掉血，但会被持续推回并减速，
HUD 会提示「脱离战场区域 · 立即返航」。贴着边界打会失去机动空间，
AI 也会把「贴边」计入风险。

## 五、调参

### 在 Inspector 里调（推荐）

选中 `Assets/Resources/Dogfight/GameConfig.asset`：

| 字段 | 作用 |
|---|---|
| `DefaultAiProfile` | 默认 AI 档位 |
| `WorldWidth` / `WorldHeight` | 战场尺寸 |
| `AiReactionScale` | 反应时间倍率，<1 更灵敏 |
| `AiAimErrorBonus` | 额外瞄准误差，调大 AI 更打不准 |
| `AiTriggerScale` | 开火克制倍率，<1 更爱乱开枪 |
| `AiEvadeThresholdOffset` | 规避阈值偏移，调小更早规避 |
| `PlayerLives` | 玩家命数 |
| `EnableParallax` | 多层视差开关 |
| `EnableGeneratedTerrain` | 程序化地表开关 |

> 注意：`GameConfig` **只暴露需要手调的旋钮**，其余全部来自
> `ConfigDefaults`（唯一的数值来源）。这样做是因为配置里有 `Dictionary`，
> Unity 序列化不了，硬序列化会在 Inspector 里看不到还会被静默重置。

### 在代码里调

想改飞行手感、武器数值、威胁权重、波次曲线，改
`Assets/Scripts/Core/ConfigDefaults.cs`，然后**跑一次自检**确认没改坏：

```
空战 → 运行核心算法自检
```

### 加新机型 / 新武器 / 新 AI 档位

都在 `ConfigDefaults.cs` 里加一条即可，仿真代码不写死任何数值。
新增 AI 行为模式用 `AiBehaviors.Register(AiMode.Xxx, fn)`，
新增路径规划算法用 `Pathfinding.Register("名字", fn)`——都不需要改现有行为代码。

## 六、常见问题

**Q：飞机转不动？**
A：看 HUD 的「空速」。低于最小速度会失速，舵效只剩三成。先加油门。

**Q：导弹按了没反应？**
A：锁定需要**按住**约 1 秒，且目标要落在机头 ±35° 锥角内、距离 1250 px 以内。
HUD 上会出现锁定进度条。中途松手会变成无制导发射。

**Q：机炮打一会儿就不响了？**
A：过热了。HUD 机炮条变红显示「过热」，等约 2.2 秒散热。

**Q：怎么快速验证我改的算法没写坏？**
A：跑 `tools\unity-verify\验证.bat`（不用开 Unity），或 Unity 菜单「空战 → 运行核心算法自检」。

**Q：为什么 HUD 是这种比较朴素的风格？**
A：第一阶段用 IMGUI 绘制，好处是**不依赖任何字体 / Canvas / TMP 资源**，
不会因为素材没配好而白屏。第二阶段会换成 uGUI + TMP，数据接口不用变。
